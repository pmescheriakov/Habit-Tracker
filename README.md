# Habit Tracker CLI

CLI-приложение на Go для отслеживания привычек. Позволяет добавлять привычки, отмечать выполнение по дням, просматривать прогресс и управлять привычками через терминал.

## Возможности

- Добавление, обновление и удаление привычек
- Отметка привычки за конкретную дату
- Просмотр списка привычек (все, активные, архивные)
- Просмотр прогресса по отдельной привычке
- Хранение данных в JSON-файле
